UPLOAD to GitHub Pages: unzip, upload all files (keep the assets/ folder).
1. Add assets/song.mp3 (music button appears only if the file exists) and assets/film.mp4 (film button appears only if it exists).
2. In config.js set siteUrl to your final https://... address (needed for the WhatsApp preview), and replace og:image in index.html with that full URL to assets/monogram.png.
3. Add gallery photos: put files in assets/ and set src in config.js gallery.
Edit wedding data in config.js, interface text in i18n.js. Bride-side link: add #bride to the URL.
